# SaaSFlow administration

The platform administrator can inspect organizations, members, projects and share counts. Access requires the trusted `ADMIN_USER_ID` in addition to a signed-in account.

From the repository root, run `pnpm --filter admin dev` and open `http://localhost:3002`. Configure the database, session secret, origin and administrator ID using the app's `.env.example`. [Workspace setup and verification](../../README.md)
